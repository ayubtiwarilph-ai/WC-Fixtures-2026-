Data sources & update policy

  • Fixtures, teams, venues, dates/times: openfootball / worldcup.json (raw JSON, public domain — CC0 1.0). Fetched directly client-side from raw.githubusercontent.com. The maintainer typically updates this dataset about once per day during the tournament. No API key required.
  • Live / final scores (optional enhancement): football-data.org free tier (10 requests/minute, requires a free personal API token you can add in config.js / browser prompt). If no token is configured, the app falls back to fixture data only and shows matches as "Scheduled" until kickoff.
  • Auto-refresh cadence: fixtures re-fetched every 6 hours (cached in localStorage); live score polling every 60 seconds, only while a match is within its expected playing window (kickoff to kickoff + 2h15m), to respect rate limits.
  • Group rosters (for standings table): openfootball / worldcup.json — 2026/worldcup.groups.json (CC0). Standings (W/D/L/Pts/GD) are computed client-side from completed match scores in worldcup.json; no separate standings API is used.
  • Nepal time conversion: computed client-side via fixed UTC+5:45 offset (Nepal does not observe daylight saving time).

Notes

  • All processing is client-side; this is a static site suitable for GitHub Pages.
  • If the openfootball feed is briefly unavailable, the app uses the last cached copy from localStorage and shows a notice.
  • This is an unofficial fan project, not affiliated with or endorsed by FIFA.
